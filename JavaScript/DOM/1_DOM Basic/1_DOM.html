DOM

DOM is Document Object Model

The whole HTML page is called as document

An OBJECT is something that has properties and methods.

In the DOM, every HTML element becomes an object.

Model is simply a representation or structure.

The browser creates a model (tree structure) of your HTML.

DOM Operations

  • Select Element
    • const button = document.querySelector("button");
  • Change Text
    • button.textContent = "Click Me";
  • Change Style
    • document.body.style.backgroundColor = "red";
  • Add Element
    • const p = document.createElement("p");
    p.textContent = "New Paragraph";
    document.body.appendChild(p);
  • Remove Element
    • document.body.removeChild(p);

DOM Accessible Elements

How can JavaScript access (find/select) HTML elements from the DOM?

  • getElementById()
    • <button id="btn">Click</button>
    const button = document.getElementById("btn");
  • getElementsByClassName()
    • <p class="text">Hello</p> <p class="text">Hi</p> const texts = document.getElementsByClassName("text");
  • getElementsByTagName()
    • <p class="text">Hi</p> const paragraphs = document.getElementsByTagName("p");
  • querySelector()
    • Select first matching element
    <p class="text">Hello</p> <p class="text">Hi</p> const p = document.querySelector(".text"); 
    OUTPUT → <p class="text">Hello</p>
  • querySelectorAll()
    • Select all matching elements
    <p class="text">Hello</p> <p class="text">Hi</p> const p = document.querySelectorAll(".text");

DOM SELECTORS

  • Element Selector
    • <button>Click</button> document.querySelector("button");
  • ID Selector
    • <button id="btn">Click</button> document.querySelector("#btn");
  • Class Selector
    • <p class="text">Hi</p> document.querySelector(".text");
  • Universal Selector
    • document.querySelector("*");
  • Multiple Elements
    • <p>Hi</p> <h1>WORLD</h1> document.querySelectorAll("h1, p");
  • Descendant Selector
    • <div>
        <p>Hello</p>
    </div> 
    document.querySelector("div p"); Find p inside div.
  • Child Selector
    • <div>
        <p>Hello</p>
    </div> 
    document.querySelector("div > p"); Find direct child p.
  • Attribute Selector
    • <input type="text"> document.querySelector('[type="text"]');
  • Pseudo-Class Selector
    • <li>One</li> <li>Two</li> <li>Three</li> document.querySelector("li:first-child");

BOM

BOM is Browser Object Model

BOM allows JavaScript to interact with the browser itself, not the HTML page.

DOM BOM
Works with HTML Works with Browser Window, Browser tab, URL, Screen size and Alerts etc.
document OJECT window OBJECT
Changes Elements Control Browser
querySelector() alert()
<p id="msg">Hello</p> alert("Welcome");
document.getElementById("msg").textContent = "Hi"; location.reload();
Note: DOM is used to access and manipulate HTML elements, while BOM is used to interact with browser features such as URL, history, storage, window, and navigation.
